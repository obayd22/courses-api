# 📚 Node.js Courses API

A RESTful API built with **Node.js**, **Express.js**, and **MongoDB** for managing courses and users. The project demonstrates backend development best practices, including authentication, authorization, validation, file uploads, and structured error handling.

---

## 🚀 Features

* User Registration & Login
* JWT Authentication
* Role-Based Authorization (Admin/User)
* Complete CRUD Operations for Courses
* Upload User Avatar Images
* Request Validation
* Centralized Error Handling
* MongoDB Database Integration
* RESTful API Design

## ▶️ Getting Started

### Clone the repository

```bash
git clone https://github.com/your-username/your-repository.git
```

### Install dependencies

```bash
npm install
```

### Create a `.env` file

```env
PORT=4000
MONGO_URL=your_mongodb_connection_string
JWT_SECRET_KEY=your_secret_key
```

### Start the development server

```bash
npm run dev
```

or

```bash
npm start
```
